# pixel-studio-site｜像素工作室

像素風個人作品集網站模板，使用純 HTML、CSS 和少量 JavaScript，無須安裝套件。

## 編輯網站

1. 在 GitHub 打開 `index.html`。
2. 點右上角鉛筆圖示（Edit this file）。
3. 搜尋範例內容，例如 `【你的名字】`、`作品 01` 或 `your.email@example.com`，改成自己的資料。
4. 點 **Commit changes** 儲存。若已啟用 GitHub Pages，網站會在部署完成後更新。

主要內容都在 `index.html`：

- 自我介紹：搜尋「嗨，我是」
- 作品卡片：搜尋 `WORK 01`，複製整個 `<article class="work-card">...</article>` 區塊可增加作品
- 聯絡信箱：搜尋 `your.email@example.com`

## 啟用 GitHub Pages

1. 打開儲存庫的 **Settings → Pages**。
2. 在 **Build and deployment** 的 **Source** 選 **Deploy from a branch**。
3. Branch 選 `main`，資料夾選 `/(root))，再按 **Save**。
4. 等 GitHub Pages 部署完成後，回到 Pages 設定頁即可看到網站網址。

網站首頁是根目錄的 `index.html`，版面會適應手機和電腦螢幕。
